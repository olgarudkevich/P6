## 📝 Висновки

Під час виконання практичної роботи було опановано основи роботи зі структурою даних «черга» (queue) у мові C++ за допомогою стандартного контейнерного адаптера std::queue. Вивчено принцип функціонування FIFO (First In, First Out) та закріплено на практиці використання методів push(), pop(), front(), back(), empty() та size(). Здійснено практичну реалізацію алгоритмів обробки числових і символьних даних, фільтрації елементів, використання структур (struct) та моделювання реальних процесів.
